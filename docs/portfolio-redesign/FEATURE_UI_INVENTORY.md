# Feature and UI inventory — source baseline

**Scope and evidence.** Audited the currently mounted React tree, data flow, server routes and styles in the working tree. `src/main.tsx` → `src/App.tsx` → `src/os/state.tsx` + `src/os/Shell.tsx` is the public route; `/admin` lazy-loads `src/admin/AdminDashboard.tsx` instead. The files under `src/apps/`, `src/components/`, `src/context/`, and `src/data/portfolioData.ts` are legacy code, **not imported by the public App/Shell dispatch**; their interactions are not current product requirements. `src/utils/deviceDetection.ts` *is* used. References below are source-verified, **not browser-verified**. Inventory IDs (`ENT-*`, `NAV-*`, etc.) are stable documentation/acceptance IDs, **not existing DOM IDs or test IDs**. Do not treat marketing copy, sample benchmarks, demo network data or simulated crypto as verified real-world evidence.

## Cross-cutting behavior and gaps

- **Viewport distinction:** layout is selected by saved `mode`/device detection, not CSS alone. Test (a) workstation on desktop, (b) workstation narrowed to tablet/phone, (c) NetHunter framed on desktop/tablet, (d) NetHunter on real mobile. At ≤900 workstation widgets + filesystem + central HUD are hidden by styles; responsive parity depends on other entries and must be checked. Phone mode is common for `ios`/`android`/`nethunter`; older iOS/Android UI code is not mounted.
- **Motion:** CSS keyframes/transitions, desktop dock pointer scale, HUD/icon/widget pointer dragging, animated project FlatList and detail transition, timed boot/handoff/replay/scan. Global `src/os/styles.css` `prefers-reduced-motion` compresses animation/transition and disables scroll smoothness; `src/os/command-center.css` disables Fast-Pass/replay effects; boot and handoff JS skip on reduced motion. Replay stage timer remains active when Play is pressed (no motion preference gate). Verify focus, scroll, touch targets and no unexpectedly moving content in browser.
- **Accessibility:** native Fast-Pass dialog and radios, buttons for most navigation, Spotlight focus loop. Filesystem launcher relies on pointer handlers, subnet cards on clickable divs, HUD/widget drag has no keyboard equivalent; window/title drag is pointer-only. Some headings/labels claim live verification and encryption while behavior is simulated; wording/semantics should be reviewed, not copied as truth.
- **Security and evidence:** resume PDFs are role assets; `safeLink` permits relative and http/https/mailto; configured data may differ from bundled seed. Public key/credentials screen simulates verification; PGP key is placeholder. SIEM stream, SOC alert, nmap, network scans, HID injection, defense, telemetry, replay and displayed benchmark claims are simulations. Verify published credential status and provenance before repeating any claims in redesign.
