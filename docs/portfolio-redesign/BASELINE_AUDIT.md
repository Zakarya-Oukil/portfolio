## Source-verified architecture and corrections to previous inventory

1. Public `/` renders `SystemProvider` + `Shell`, `/admin*` lazy-loads admin (`src/App.tsx`); this is pathname/popstate detection, not a route framework. `src/os/Shell.tsx` imports active applications from `src/os/Apps.tsx`, `Projects.tsx`, recruiter and specialist modules. **Do not treat** `src/apps/ProjectsApp/*`, `src/apps/TerminalApp/TerminalScreen.tsx`, `src/apps/SettingsApp/SettingsScreen.tsx`, `src/apps/ContactApp/ContactScreen.tsx`, old `src/components/DeviceFrame/*`, `src/context/OSContext.tsx` or `src/data/portfolioData.ts` as live dependencies. Their prior claimed keyboard shortcuts, mail attachments, settings controls, project keyboard carousel and device UI were spurious. `src/utils/deviceDetection.ts` remains used.
2. Fast-Pass is a native modal `<dialog>` (`src/os/RecruiterFastPassDrawer.tsx`) opened by Ctrl/Cmd+K, workstation top bar/dock, mobile home pill and incident replay. **Ctrl/Cmd+Shift+K** toggles Spotlight; Ctrl/Cmd+, opens Settings. Native Escape closes Fast-Pass and restores previous focus; the global Shell key handler exits while it is open. Spotlight has its own focus loop. The former claim that Ctrl/Cmd+K toggles Spotlight/Fast-Pass interchangeably is false.
3. Phone modes (`ios`, `android`, `nethunter`) all render `src/os/Mobile.tsx` **NetHunter**. `macos` and `desktop` render `src/os/Desktop.tsx` workstation. The saved mode can override UA detection and CSS narrowing does not reselect the OS. Despite residual boot/handoff labels suggesting macOS/iOS/Android, there are no active iOS Dynamic Island/Android system bar implementations in the current shell.
4. The authoritative server endpoints (`server/portfolio-api.mjs`) are **GET `/api/portfolio-data`, POST `/api/portfolio-data` (admin), POST `/api/mail`, GET `/api/admin/session`, POST `/api/admin/login`, POST `/api/admin/logout`, GET `/api/messages` (admin), POST `/api/messages/delete` (admin)**. There is **no** `/api/inquiry`, `/api/auth/login`, `/api/auth/logout` or `/api/upload`. Admin file input reads images into draft as a data URL rather than posting an upload endpoint. `server/start.mjs` serves the built SPA and calls this API; Vite plugs the same API into dev/preview.
5. Portfolio content originates from `src/data/seed.json` (bundled fallback) or `server/data.json` via public GET; `src/os/portfolio-store.ts` caches `zak.portfolio.v2` and validates a basic shape; admin browser draft uses `zak.portfolio.draft.v2`, and publishing writes validated server JSON. Admin publish failure falls back to **this browser only** with `_localOnly`; it is not a global publish. Mail inquiries are **saved** to the private server inbox, not automatically emailed or calendared. Build root is `index.html`, not `public/index.html`.
6. The role selector offers pentest/SOC/systems, matching evidence apps and PDFs at `/resumes/Zakarya_Oukil_{Pentest,SOC,Systems}_CV.pdf`; files exist in `public/resumes/`, but existence alone does not verify browser downloads/content. Booking URL switches to an external HTTP(S) link when configured; absent URL opens a proposed-time form. Priority email switches to `mailto:` when configured; otherwise inline inquiry. Both forms POST `/api/mail`. A PGP key link is optional and the launcher does **not** encrypt submissions. A proposed technical screen is **not a calendar reservation**.
7. Workstation widgets/HUD/filesystem disappear at ≤900px via CSS while the `mode` may still be desktop. Mission HUD telemetry (VPN/clearance/certs) and desktop workspace number are configured/decorative; workspace switch changes local highlight + toast only. Widgets can snap-drag, but do **not** persist positions. Filesystem launches on pointer-up rather than `onClick` and has no explicit keyboard activation; subnet host cards are clickable divs. Preserve alternate access paths and check keyboard parity before using those controls as primary navigation.
8. `Projects.tsx` (active) provides desktop gallery and mobile animated FlatList carousel, saves, detail and technical overview. It lacks declared Ctrl/Cmd+F focus or arrow-key carousel navigation. `Apps.tsx` terminal has Up/Down, Tab, Ctrl+L and Enter only (no Ctrl+C/Ctrl+R process support). Active Mail persists draft and offers `.eml` backup **after** successful POST (not attachments or full local-only draft export). Settings presents theme/wallpaper/mode/GitHub; audio toggle lives in top panel.
9. Several named features are explicitly simulations: terminal `nmap`, DuckHunter HID injection, Subnet Radar scanning, SIEM stream, defense exercise, replay packet/event logs, SOC script, and CPU/network telemetry. `CredentialSigModal.tsx` contains a truncated placeholder public key and a timed fake GPG verification; it **does not authenticate credentials**. Pentest report download and thesis abstract are `.md` files, not PDFs. Research chart metrics/benchmark copy are displayed data, not measurements established by this audit. Future design must not promote simulated values or certification progress into independently verified credentials.
10. `src/os/BootAnimation.tsx` and `Transition.tsx` skip animations when reduced motion is requested, and CSS globally minimizes animations plus Fast-Pass/replay-specific effects. Replay still advances at 6.5 seconds per stage when Play is pressed; no scrubber, per-stage animation timeline, Space-to-play or arrow-key controls. `src/os/Transition.tsx` handoff label text is inconsistent with current Kali branding. These are source findings, not empirical judgments about runtime smoothness.

## Open decisions for entry and Fast-Pass redesign

- Decide whether a new entry CTA offers Workstation, NetHunter and Recruiter Fast-Pass immediately, while keeping saved-mode semantics and a non-blocking first visit; current implementation offers mode switches within OS, **not** a standalone entry chooser. This is a proposed future behavior, not baseline.
- Preserve all three recruiter role mappings, evidence routes and direct PDF access. Keep public contact capabilities truthful: form = saved inbox request, booking = proposed time unless configured external booking, key link ≠ encryption; do not infer real signature/benchmark validation from adjacent specialist apps.
- Make mobile and narrowed-desktop entry independent of hidden filesystem/HUD/widgets. Use stable inventory IDs to trace controls across old and new UI, then replace `BU`/`P` in the matrix only after real browser tests; passing Node tests/build alone cannot close them.
- No historical scripts, publishing, content mutation, deployment, or changes outside these three inventory/coverage/audit documents were performed by this audit agent.
